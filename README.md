# 🐱💻 Игра «Кот-хакер»

**Telegram-бот с мини-игрой в жанре «хакерского симулятора».** 
В роли главного героя выступает хитрый кот, который взламывает умные приборы по всему дому — от умного чайника до холодильника с ИИ. Игра реализована в виде Telegram-бота, что позволяет играть прямо в мессенджере без установки отдельных приложений.

---

## 🎮 О проекте
Проект представляет собой интерактивную текстово-кнопочную игру внутри Telegram. Игрок управляет котом-хакером, выполняя миссии по «взлому» умных устройств. Каждый уровень — это новый прибор с уникальной механикой и сложностью. За успешное прохождение уровней начисляются баллы и выдаются награды (достижения, скины, артефакты).

---

## ✨ Функционал

### 1. 🚀 Запуск игры командой `/start`
* **Приветственный экран:** Бот встречает пользователя, представляет сюжет и главного героя — кота-хакера.
* **Обучение:** Краткий туториал с объяснением механики игры.
* **Главное меню:** Inline-кнопки для навигации

### 2. 🔓 Взламывай умные приборы
* **Разнообразие целей:** Игрок последовательно взламывает умные устройства:
 * 🤖 Робот-пылесос
 * 🧊 Холодильник

## 🛠 Использованные технологии

| Технология | Применение в проекте |
| :--- | :--- |
| **Java** | Основной язык разработки. Серверная логика бота, обработка состояний игры. |
| **Telegram Bot API** | Официальный API Telegram для отправки/получения сообщений, работы с inline-кнопками, callback-запросами, управления обновлениями. |
| **Telegram** | Платформа взаимодействия с пользователем. Бот работает как контакт в мессенджере, что обеспечивает мгновенный доступ без установки приложений. |
| **Maven / Gradle** *(доп.)* | Система сборки Java-проекта, управление зависимостями (библиотека для Telegram Bot API). |
| **Библиотека TelegramBots** *(доп.)* | Популярная Java-обертка над Telegram Bot API, упрощающая работу с методами API. |

## 📱 Как играть

1. Найдите бота в Telegram по имени.
2. Нажмите **Start** или отправьте команду `/start`.
3. Ознакомьтесь с сюжетом и туториалом.
4. Выберите **«Начать игру»** и приступайте к первому уровню.
5. Выполняйте задания, используя inline-кнопки и текстовые команды.
6. Получайте баллы, открывайте новые уровни и собирайте награды!
